 # 🎓 Campus Placement Portal

## 📌 About the Project

The Campus Placement Portal is a web application developed for **Vishnu Institute of Technology**. It simplifies the campus recruitment process by connecting students, recruiters, and administrators on a single platform.

The system helps administrators manage placement activities, allows students to apply for jobs, and enables recruiters to post job opportunities and review applications.

---

## 🚀 Features

### 👨‍🎓 Student
- Student Registration & Login
- View Available Jobs
- Apply for Jobs
- Track Application Status
- Update Profile

### 👨‍💼 Admin
- Secure Admin Login
- Add, Edit and Delete Job Postings
- Manage Student Applications
- View Placement Statistics
- Manage Recruiters

### 🏢 Recruiter
- Company Registration
- Post Job Opportunities
- View Eligible Students
- Manage Applications

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/lahari-sai972/campus_placement_portal.git
```

### Go to the Project Folder

```bash
cd campus_placement_portal
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Start Backend

```bash
npm run dev
```

### Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### Start Frontend

```bash
npm run dev
```
